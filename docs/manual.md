# AZ-104 ローカル試験アプリ マニュアル

パチスロ収支基盤を Azure に載せた世界線で、AZ-104 を Udemy 型に解くためのアプリです。  
ブラウザは **http://127.0.0.1:5104/** だけ使います。GCP の正本 SQLite には接続しません。

- セット1: **60 問**、制限 **100 分**、合格目安 **70%**
- 選択肢は 4〜5。正解は 1〜3 個。指定個数をすべて当てて 1 問正解（部分点なし）
- 学習用に正誤ログ・試験日までの予定・メモ・壁打ち AI があります

---

## 1. 起動

### 必要なもの

- Python 3.11 前後（3.10 以上を想定）
- ブラウザ（Chrome / Safari など）
- 壁打ちだけ使う場合: [Google AI Studio](https://aistudio.google.com/) の Gemini API キー

収支アプリ（port 5000）と同時に動かして構いません。ポートが違います。

### 1回目（クローン直後）

GitHub から取った場合:

```bash
git clone git@github.com:izumi777777/Azure-AZ104.git
cd Azure-AZ104
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

すでにディスク上の `Azure-AZ104/` がある場合は、`clone` は不要です。`cd` して venv 以降だけ実行します。

### 2回目以降

```bash
cd Azure-AZ104
source venv/bin/activate
python3 app.py
```

起動ログに `Running on http://127.0.0.1:5104` が出たら、その URL をブラウザで開きます。

`flask --app app run --host 127.0.0.1 --port 5104` でも同じです。`--host 0.0.0.0` は使わないでください。

### 停止

ターミナルで `Ctrl+C` します。ブラウザを閉じてもプロセスは残ります。

### 起動でよくあること

| 症状 | 対処 |
|------|------|
| `Address already in use` | 別プロセスが 5104 を使っています。`lsof -iTCP:5104 -sTCP:LISTEN` で PID を見て止めるか、そのプロセスを使います |
| 画面が古い | `debug=False` のためコード変更は再起動が必要です。`Ctrl+C` して `python3 app.py` |
| `ModuleNotFoundError: flask` | `source venv/bin/activate` を忘れています |
| 問題が 36 問のまま | `questions/set01.json` が古いです。`python3 scripts/build_set01.py` で作り直してから再起動 |

問題 JSON を手で直したあとも、サーバーを再起動してください（ファイルの更新日時で読み直しますが、起動中の受験セッションはそのままです）。

## 2. 画面の全体像

上部ナビはどのページからも同じです。

| ナビ | 役割 |
|------|------|
| 試験 | ホーム。セット開始と、今日の予定・正答率の要約 |

データはすべて `data/attempts.sqlite` に残ります。git には上がりません。ブラウザを閉じても、受験結果・メモ・予定は残ります。

## 3. 試験と練習

### 開始

1. ホームでモードを選ぶ
2. **開始** を押す

| モード | 動き |
|--------|------|
| 試験 | 提出するまで正解も解説も出さない。本番に近い |
| 練習 | 各問で **答え合わせ** ができる。解説がその場で出る |

制限 100 分は目安です。切れても続行できます。タイマー切れで強制提出はしません。

### 1問の操作

- 「1つ選べ」はラジオ、「2つ選べ / 3つ選べ」はチェックボックス
- 複数選択で指定個数を超えると、最後に押した印は外れます
- **前へ / 次へ** で移動。右の番号パレットでも飛べます
- **フラグ** は後で見直す印（オレンジ）。採点には使いません
- 練習だけ **答え合わせ** があります。選んだあと押すと正誤と解説が出ます。この操作が正誤ログに 1 行残ります

パレットの色:

- 暗い: 未回答
- 青み: 回答済
- オレンジ枠: フラグ
- レビュー時は緑＝正解、赤＝不正解

回答は問を離れる（次へ・パレット・答え合わせ）ときに保存されます。

### 提出

1. 右下の **試験を終了**、または最後の問の **終了へ**
2. 未完成の問番号が出るので、必要なら戻って埋める
3. **採点する**

未回答は不正解です。途中の「答え合わせ」では試験は終わりません。

提出すると 60 問ぶんが正誤ログに載ります。同じ受験を二度採点しても、試験ログは二重に増えません。

## 4. 結果と解説

結果画面に総合点と領域別バーが出ます。70% 以上で「合格目安を超えました」と出ます。これは公式の 700 点スケールではありません。

**解説を見る** で 1 問ずつ、自分の選択と正解を対照できます。

解説画面では:

- **この問題を壁打ちする** → その問をコンテキストにした AI
- **メモを残す** → 題名と本文がその問に紐づく

---

## 5. 正誤ログ

練習の答え合わせと、試験の提出結果を問題ごとに集計します。並びは正答率が低い順です。

- 領域バー: いま弱いスキルが見える
- 最近の不正解: そこから壁打ちへ
- 受験履歴: 過去の提出結果へ戻れる

ホームの「領域の正答率」も同じ集計です。ログが空のときは、まず練習で答え合わせするか、試験を 1 回提出してください。

起動時に、古い提出結果でログ表が空なら一度だけ埋め戻します。

## 6. 学習スケジュール

1. **予定** を開く
2. 試験日を入れる（今日以降）
3. **予定を作り直す**

作り方:

- 試験日まで、5 領域（ID・ストレージ・コンピュート・ネットワーク・監視）を日替わり
- 正誤ログがある場合、6 日に 1 回「弱点の追加日」が入る
- 直近 3 日は **弱点の解き直し → 60 問通し → 直前メモ**
- 残り 1〜2 日しかないときは、短縮版になる

各行の **未 / 済** で進捗を付けます。ホームの「今日の予定」に反映されます。

**試験日だけ保存** は日付だけ変えて、既存の日次プランは消しません。  
**予定を作り直す** は日次プランを全置換します。済チェックも消えます。

---

## 7. メモ

**メモ** から題名・本文・任意で関連問題を選んで保存します。解説画面からも同じことができます。

一覧の題名をクリックすると編集、削除は確認のあと消えます。  
壁打ちで問題を選ぶと、その問のメモも Gemini に渡ります。自分の言葉で書いておくと復習向きです。

---

## 8. 壁打ち AI

復習で「なぜ他の選択肢がダメか」「この語が曖昧」を聞く相手です。公式問題や Udemy の文言は再現させません。

### キーの置き方（どちらか）

1. 壁打ち画面の欄にキーを入れて **キーを保存**  
   保存先は `data/attempts.sqlite` だけです。git に出ません。
2. 起動前に環境変数

```bash
export GEMINI_API_KEY="自分のキー"
python3 app.py
```

画面に保存したキーが優先されます。未設定のあいだ **送る** は押せません。

モデルは `gemini-2.5-flash` です。収支アプリ側のキーとは共有しません。

### 使い方

1. 「この問題について聞く」で問を選ぶ（任意）。選ぶと本文・正解・解説・メモが渡る
2. 質問を書いて **送る**
3. スレッドは問題ごと（未選択なら全体用）に残る。**このスレッドを消す** でその会話だけ消える

インターネットに出ます。API キーや本番の秘密を質問文に書かないでください。

---

## 9. データの場所

| パス | 内容 | git |
|------|------|-----|
| `questions/set01.json` | 出題の正本 | コミットする |
| `data/attempts.sqlite` | 受験・正誤・予定・メモ・壁打ち・API キー | しない |
| `data/secret_key` | Flask の cookie 署名 | しない |
| `venv/` | 仮想環境 | しない |

SQLite を消すと学習記録は消えます。問題 JSON は消えません。  
別マシンに移すときは、アプリ一式に加えて `data/attempts.sqlite` をコピーすれば記録も移せます。`secret_key` を変えると、途中の受験セッション cookie は無効になります。
